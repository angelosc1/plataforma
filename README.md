# 🎮 Plataforma de Jogos

Bem-vindo à plataforma de jogos em estilo vermelho e claro, criada para ser responsiva e pronta para o GitHub Pages.

## ✨ O que há aqui

- Uma página inicial moderna e visualmente agradável
- Jogos locais já inclusos
- Links para outros jogos externos
- Design responsivo para celular, tablet e desktop

## 🕹️ Jogos disponíveis

### Jogos locais
- Jogo da Forca
- Snake
- Corrida 3D

### Jogos externos
- Mascote Virtual Espacial
- Jogo do Gato
- Jogo da Memória

## 📱 Responsividade

A interface foi pensada para oferecer uma experiência fluida em diferentes tamanhos de tela, com foco em dispositivos móveis.

## 🚀 Como publicar no GitHub Pages

1. Envie este projeto para um repositório no GitHub.
2. Acesse as configurações do repositório.
3. Vá até a seção "Pages".
4. Selecione a branch principal e a pasta raiz do projeto.
5. Salve e aguarde a publicação.

## 🌟 Inspiração visual

A plataforma utiliza uma paleta em tons de vermelho, branco e claro para transmitir energia, diversão e simplicidade.
